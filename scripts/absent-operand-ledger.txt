# The counted `absent-operand-becomes-a-number` backlog for
# scripts/check-absent-operand-default.py.
#
# Each line is `<enclosing function> <count>`: that many places inside that
# function supply a numeric default for an operand the user did not give, so a
# missing id becomes a real one. See that script's header for why the
# definition lives in code and the count lives here.
#
# The number may only go DOWN. An entry claiming more sites than exist fails
# too, because that is how a fixed site stays counted.
#
# An `allow <function> <literal>` line exempts one (function, default) pair.
# It exists because this population is not one population. Every default that
# names an object is 0 or 1 -- `filevault unlock` with no argument unlocks
# vault 0 -- while every default that names a QUANTITY is larger: a row count,
# an idle delay in seconds, a percentage, a timeout in milliseconds. Supplying
# 300 seconds for an omitted `screensaver timeout` is not a guess about what
# the operator meant; it is the documented default of an optional operand.
#
# So the floor of this ledger is NOT zero, and a reader who drives it to zero
# deletes working defaults. The allowed lines are the difference, each with the
# synopsis that makes it optional.
#
# A blessing is keyed on the literal, not a line number: line numbers in a
# 120k-line file move every batch, and the literal is the thing that decides
# which population a site belongs to. An allow line matching no site in the
# tree FAILS, for the same reason an over-claiming count does.
#
# These lines say nothing about the OTHER defect on the same source line. Each
# allowed site also writes `.parse().unwrap_or(N)`, replacing a word it could
# not read with a guess -- design-decisions.md 600's shape, counted separately
# in scripts/option-refusal-ledger.txt, where all six functions already
# appear. Blessed here means blessed for the absent-operand question only.
#
allow cmd_sharesheet 10 # `sharesheet history [count]` -- rows to list, not a target id
allow cmd_screensaver 300 # `screensaver timeout [secs]` -- an idle delay, not a saver id
allow cmd_apppermissions 10 # `apppermissions log [count]` -- rows to list, not an app id
allow cmd_sysanimations 100 # `sysanimations speed [pct]` -- 100 percent means unchanged
allow cmd_filevault 300 # `filevault autolock [secs]` -- a delay, not a vault id
allow cmd_udp6 5000 # `udp6 listen [timeout_ms]` -- how long to wait, not a socket id
