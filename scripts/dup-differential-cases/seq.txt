# Cases for `seq`. Format: label | stdin | argv...
#
# `seq` takes no stdin, so the middle field is empty throughout. It is a good
# differential target precisely because it is pure computation: every answer is
# fully determined by the arguments, so a disagreement is always a defect in
# one side and never an environment difference.
#
# Weighted towards the places a naive implementation goes wrong: floating point
# accumulation, a step that cannot reach the end, an increment of zero, and the
# width rule for `-w`, which GNU derives from the widest *formatted* value and
# not from the arguments as written.

# -- the three argument forms --
one arg               |  | 5
two args              |  | 2 5
three args            |  | 1 2 9
first equals last     |  | 3 3
last below first      |  | 5 2
negative first        |  | -3 3
negative range        |  | -5 -2

# -- increments --
negative increment    |  | 5 -1 1
negative incr wrong way |  | 1 -1 5
zero increment        |  | 1 0 5
increment overshoots  |  | 1 4 10
increment exact       |  | 1 3 10

# -- floating point, where accumulation error shows --
float step            |  | 1 0.1 2
float step thirds     |  | 0 0.3333333333 1
float endpoints       |  | 1.5 2.5
float negative step   |  | 2 -0.5 0
float tiny step       |  | 1 0.0000001 1.0000005
float precision carry |  | 0.1 0.1 0.5

# -- equal width --
equal width           |  | -w 1 10
equal width negative  |  | -w -5 5
equal width float     |  | -w 0.5 0.5 2
equal width three dig |  | -w 98 102
equal width one value |  | -w 7 7

# -- separator --
separator comma       |  | -s , 1 5
separator empty       |  | -s '' 1 3
separator newline     |  | -s '\n' 1 3
separator multichar   |  | -s '--' 1 3

# -- format --
format integer        |  | -f %03g 1 3
format float          |  | -f %.2f 1 3
format percent        |  | -f %g%% 1 2
format invalid        |  | -f %d 1 3

# -- refusals and edges --
no arguments          |  |
too many arguments    |  | 1 2 3 4
non numeric           |  | abc
non numeric second    |  | 1 abc
empty argument        |  | ''
plus prefixed         |  | +1 +3
leading zeros         |  | 01 03
hex input             |  | 0x1 0x3
infinity              |  | 1 inf
nan                   |  | nan
