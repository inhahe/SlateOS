# Fields: crate<TAB>field<TAB>reason

# WHY THIS FILE EXISTS. The survey finds fields that are read and never
# written. Some of those are not defects, and no scanner can tell which: a
# measurement computed once and correctly never changed, a setting whose
# feature deliberately does not exist yet and says so on screen, a decision
# already put to the operator. Without somewhere to record that, every run
# re-offers the same rows and the same investigation happens again -- which
# it has, twice.
#
# This is NOT a suppression list for inconvenient findings. Two rules:
#
#   * Every line carries a reason, and the reason has to say what *makes* it
#     not a defect -- not that it is known.
#   * A line naming a field the survey no longer reports is an error, not a
#     no-op. The tool says so. An answer that has rotted is worse than no
#     answer, because it reads as a decision somebody made about the code as
#     it is now.
#
# Run `python scripts/frozen-flag-survey.py --answered` to see these rows
# with their reasons instead of hiding them.
