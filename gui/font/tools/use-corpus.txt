# Corpus for the Universal Shaping Engine, swept against every installed face
# with
#
#     python gui/font/tools/harfbuzz_sweep.py \
#         --corpus gui/font/tools/use-corpus.txt
#
# Unlike the Khmer and Myanmar corpora this one is aimed at the host's real
# fonts rather than at a synthesized probe, because for once the host has some:
# `script_survey.py` reports faces declaring `tibt`, `java`, `bali`, `sinh`,
# `tfng`, `cham` and `bugi`. Seven scripts is not eighty-eight, but it is seven
# more than the other three shapers had, and between them they cover the three
# things the engine actually does — cluster the run, move a pre-base vowel,
# and give a broken cluster a dotted circle.
#
# Every line is one edge. Lines in scripts no installed face declares are kept
# deliberately: they shape to boxes on both sides today, and they are the
# regression test for the day a face for them is installed.
#
# The escapes are `harfbuzz_sweep.py`'s, the same ones `shape_dump.rs` reads.
# A line starting with `!` is one the two halves cannot be asked the same
# question about — a run of more than one script, where HarfBuzz guesses a
# single script for the whole buffer and we itemize. Those are counted apart.

# --- Sinhala (`sinh`, Nirmala.ttc) ---
# The plainest cluster there is: one consonant.
\u0d9a
# Consonant + al-lakuna, a visible virama that ends the cluster.
\u0d9a\u0dca
# KOMBUVA is a pre-base vowel: the engine has to move it in front of the KA
# that it follows in the text.
\u0d9a\u0dd9
# KOMBUVA DEKA, the two-part vowel: one character, two pieces, and the pre-base
# half must end up on the far side of the consonant from the post-base half.
\u0d9a\u0ddc
# Rakaransaya: KA, al-lakuna, ZWJ, RA. The ZWJ is hidden from the grammar and
# joins the cluster in front of it — get the filter wrong and this is two
# clusters, which is one dotted circle too many.
\u0d9a\u0dca\u200d\u0dbb
# Yansaya, the same shape with a different consonant behind it.
\u0d9a\u0dca\u200d\u0dba
# The other ZWJ idiom: touching consonants, where the ZWJ comes *first*.
\u0d9a\u200d\u0dca\u0dbb
# A word: \u0dc3\u0dd2\u0d82\u0dc4\u0dbd = "Sinhala".
\u0dc3\u0dd2\u0d82\u0dc4\u0dbd
# A vowel sign with nothing to hang on: a broken cluster, and the only kind
# that earns a dotted circle.
\u0dd9
\u0dca
