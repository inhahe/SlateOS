## Resolved — lane E

- E-Q1 [which speech-recognition engine, and does its model ship with the system?] -- resolved 2026-10-09, **Claude's recommendation: whisper.cpp, its model an optional package offered when dictation is first turned on** (§1235).
- E-Q2 [where does the weather app get forecasts, given the supplier learns where the user is?] -- resolved 2026-10-09, **Open-Meteo, but off until the user turns it on; no program contacts a website by default unless that is what it is for** (§1236, narrowing §1214).
- E-Q3 [should System Restore cover the system's own files?] -- resolved 2026-10-09, **Claude's recommendation: no; an update is undone through package generations, whole-disk snapshots wait for a copy-on-write filesystem** (§1237).
- E-Q4 [which of the two recycle bins is SlateOS's?] -- resolved 2026-10-09, **Claude's recommendation: the home bin, one per drive with each drive's own age, size and count limits, a service taking it over later** (§1238).
- E-Q5 [opening a program twice can lose data: one window, or windows that share their changes?] -- resolved 2026-10-09, **Claude's recommendation: record-by-record saving where two windows are useful, one window for the rest** (§1239).
