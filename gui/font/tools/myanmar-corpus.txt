# Corpus for `MyanmarProbe.ttf` (see `gen_myanmar_probe.py`), swept with

#         --fonts gui/font/tools/myanmar-probe \
#         --corpus gui/font/tools/myanmar-corpus.txt

# One string per edge of the Myanmar shaper rather than sampled text. On this
# face every feature announces itself by appending a marker glyph, so each line
# below asks two questions at once: did the syllable come out in the right
# order, and did the right features reach each of its glyphs in the right
# order. The second question is the one no installed face can be asked — only
# two of the 556 here register `mym2` at all.
#
# The escapes are `harfbuzz_sweep.py`'s, the same ones `shape_dump.rs` reads.

# written into the font in reverse that order cannot be an accident of lookup
# numbering. The control for every line below.
