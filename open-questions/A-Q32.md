## A-Q32 — [A] What should pressing the PC's power button do while SlateOS runs? — Status: OPEN (raised 2026-10-31)

**In short:** SlateOS now notices the power button: before, the firmware
cut the power. A setting says what a press does, and its default is
"sleep". SlateOS cannot sleep yet, so for now a press shuts the machine
down in order, logging that sleep was not available. You are asked what a
press should do, now and once sleep exists. Windows on the test PC is set
to shut down on a press, which suggests your answer, but this is about
every SlateOS machine's default.

**Terms.** *Sleep* (ACPI S3): the machine stops with its memory kept
powered, and wakes in seconds to where it was. *Shut down in order*: files
written out and the machine powered off. Today that means the kernel's
service table marked stopped, filesystems synced and logs flushed. Running
programs are not asked to save and stop yet: that needs a userspace init
that handles shutdown (known-issues
A-POWER-BUTTON-SHUTDOWN-ASKS-NO-PROGRAM-TO-STOP).

| Option | *What changes:* |
|---|---|
| **A. Shut down, now and later** (default "shut down") | A press always powers the machine off in order, as Windows on the test PC does now. |
| B. Sleep once SlateOS can; shut down until then (today's behaviour) | Today a press shuts down. Once sleep exists, a press sleeps instead. |
| C. Do nothing until sleep exists, then sleep | Until then a press does nothing. Only holding the button for 4 s, which cuts the power, turns the machine off. |

- **A** is what a desktop is usually set to, and what you chose for Windows.
  A laptop may want B; the setting can still say otherwise per machine.
- **B** is the spec's other default and today's code. The behaviour of the
  button changes later without anyone changing a setting.
- **C** keeps to the setting literally, but leaves the button useless for
  now.

**Recommendation:** A, for a desktop default, with sleep chosen in the
setting where it is wanted.

**If never answered:** B stays: a press shuts down in order today and
sleeps once sleep is built. Nothing is unsafe and nothing is blocked.

**Where:** `kernel/src/fs/power.rs` (`PowerConfig::power_button_action`,
default `Sleep`); `kernel/src/acpi/events.rs` (`pressed`, which maps an
unavailable sleep to shutdown); design-decisions 1597.
