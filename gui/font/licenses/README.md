# Third-party code in `osfont`

Parts of this crate are ports of FreeType and HarfBuzz, and its generated
tables are made from other projects' data. A port, or a table made from
someone's data, is a derivative work, and each upstream's licence asks that
its notice travel with the code. This file says what derives from where, and
the licences are beside it. `notices.yaml` is the same list for
`scripts/gather-notices.py`, which puts the notices in every image
(design-decisions.md §1433).

## FreeType

Portions of this software are copyright © 2023 The FreeType Project
(www.freetype.org). All rights reserved.

The auto-hinter in `src/hint/` is a port of FreeType 2.13.2's `autofit`
module, and the arithmetic and variable-font readers it depends on follow
FreeType's, so that the hinter sees the points FreeType's loader would give
it. They are used under the FreeType License, `FTL.TXT` in this directory:

| File | Derived from (FreeType 2.13.2) |
|---|---|
| `src/hint/tables.rs` | `src/autofit/afscript.h`, `afstyles.h`, `afranges.c`, `afblue.dat` (generated by `tools/gen_autofit_tables.py`) |
| `src/hint/glyph.rs` | `src/autofit/afhints.c` |
| `src/hint/latin.rs` | `src/autofit/aflatin.c` |
| `src/hint/cjk.rs` | `src/autofit/afcjk.c`, `afindic.c` |
| `src/hint/fixed.rs` | `src/base/ftcalc.c`, `include/freetype/internal/ftobjs.h` |
| `src/hint/mod.rs` | `src/autofit/afglobal.c`, `afshaper.c`, `afloader.c` |
| `src/ftcalc.rs` | `src/base/ftcalc.c`; the conversion macros of `src/truetype/ttgxvar.c` |

The ported code is a translation into Rust, changed from the original as
`src/hint/mod.rs` describes: only light hinting's paths, and bounds-checked
throughout. Each file in the table carries the copyright notices of the
FreeType files it derives from in its module documentation.

The LCD filter weights in `src/raster.rs` (`FT_LCD_FILTER_DEFAULT`) are
FreeType's as well.

## HarfBuzz

Portions of this software are from HarfBuzz 14.3.0, copyright its authors as
`harfbuzz-COPYING` lists them, and are used under HarfBuzz's licence (the "Old
MIT" licence), `harfbuzz-COPYING` in this directory.

HarfBuzz is this crate's oracle: its shaping and measuring are held to
HarfBuzz's output glyph for glyph (design-decisions.md §448). The files below
go further and follow HarfBuzz's *source* -- transcribed, or generated from
HarfBuzz's own grammars and tables. Each hand-written one carries the
copyright lines of the HarfBuzz files it follows in its module
documentation; each generated one names its source in its header.
