# One string per edge of the Khmer shaper rather than sampled text: the probe
# face's whole purpose is to reach the edges real text reaches rarely, and on
# a face where every feature announces itself the interesting question is
# *which* features reached *which* glyph, not whether a word looks right.
#
# The escapes are `harfbuzz_sweep.py`'s, the same ones `shape_dump.rs` reads.
