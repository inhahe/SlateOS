# The counted `guessed-value` backlog for scripts/check-option-refusal.py.
#
# Each line is `<enclosing function> <count>`: that many places inside that
# function read a word the user typed, fail to parse it, and substitute a
# default -- design-decisions.md §600's second prohibited shape. They are
# recorded rather than exempted, so that:
#
#   * the number is visible and can only go down;
#   * a NEW site in a function not listed here, or one site too many in a
#     function that is, fails the check immediately;
#   * an entry claiming MORE sites than exist is itself reported, because
#     that means the site was fixed (lower the count) or the function was
#     renamed (the entry now exempts something it was never meant to).
#
# Keyed by function, never by line number: line numbers drift on every edit,
# and an allowlist that rots is a rubber stamp.
#
# Do not add a function here to buy silence for new code. The only legitimate
# edits are downward, and deleting a line entirely is the goal.
#
# Burn-down is tracked in known-issues.md as
# `A-KSHELL-A-HUNDRED-AND-NINETEEN-FUNCTIONS-GUESS-A-VALUE-FOR-A-WORD-THEY-COULD-NOT-READ`.
